# Data Folder

This folder is used to store raw datasets locally before running the code.

Raw datasets are not included in this repository.

Expected raw files:

- `ratings.dat`
- `ratings_Beauty.csv`
- `ratings_Video_Games.csv`
- `steam_reviews.json`
- `train_corpus_total_dual.txt`
- `test_corpus_total_dual.txt`

You may also specify dataset paths manually with the `--raw_path` argument.
